# 44-paper action matrix: pretrained-first, 14 days

Archive snapshot: 2026-10-10; official release checks: 2026-10-23, listed separately in [release audit](evidence/release_audit_2026-10-23.json). Every entry links its original PDF and teaching note. Method and author-limit statements are attributed to the paper sections identified in each note; if a precise page/section has not been checked for a statement, it is labeled as integration inference. This matrix is a plan, not a measured ranking.

## Decision frame

The **candidate** first path remains RealDenseFace ViT-B → shared FLAME scene → OpenDelight image-space albedo projected to UV → DECA detail mechanism → explicit parametric eyes → nvdiffrast fitting/Blender Cycles output. Prior selection does not establish superiority: alternatives below are comparison candidates. Days 1–14 use available pretrained inference and deterministic integration only; retraining is deferred. No weights/data were downloaded, no model was run and no GPU result was measured. Do not report numerical results before a valid run.

Comparisons must use permitted inputs, matched crops/cameras/scene/light where applicable, consistent subject splits, explicit failure counts and recorded code/config/weight hashes, device/backend, latency and peak memory. Keep geometry, identity, expression, albedo, material, detail, eye and rendering metrics separate. A model release, advertised checkpoint, acquired checkpoint and executed checkpoint are four different states.

## 01_RealDenseFace
[Original PDF](../pdfs/01_RealDenseFace.pdf) · [note](../notes/01_RealDenseFace.md). **Role/method:** geometry; dense UV correspondence and relative-depth priors fitted to FLAME with CUDA Gauss–Newton (paper §§3–4 per note). **Limit (our integration inference):** occlusion/camera/domain shift; hidden geometry is underconstrained (integration implication). **Access:** Checked 2026-10-23, [advertised_code_and_weights](https://github.com/LinzhouLi/RealDenseFace). Official README says inference/fitting and pretrained models were released; ViT-S and ViT-B checkpoints downloadable via Google Drive; single-image path defaults ViT-B. FLAME2023 separately licensed. Training data marked coming soon. **Baseline/test:** primary ViT-B single-image candidate; compare ViT-S only if resource fallback is needed. **No-retrain improvement:** test development-only scalar reliability tuning or robust weights, sweep focal length, and record extra cost; neural gate training is deferred. **Ultimate:** train calibration/robustness with subject-disjoint scan/occlusion labels and GPU. **Eval/status:** posed/neutral scan error, reprojection, identity, time/memory; execute first after asset gate.
