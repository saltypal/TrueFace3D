# Fourteen-day roadmap

Day numbers are execution days, not proof that prerequisites are satisfied. The user owns daily time and resource availability. The schedule reserves the last four days for a valid integrated result rather than adding features until the deadline. New network training is outside these fourteen days.

## Time boxes

Use focused attempt budgets rather than unlimited retry loops. Suggested initial budgets, adjustable on Day 1: essential upstream environment/asset diagnosis up to half an execution day per candidate; incompatible topology transfer up to half a day before recording a fallback; heavy material model trial at most one prepared attempt after the native baseline exists. These are planning ceilings, not reasons to skip evidence or destructive shortcuts.

If Day 2 geometry fails, use Day 3 for a verified alternative/configuration on an available backend. If no geometry method can execute with permitted assets by the end of Day 3, stop claiming an executable fourteen-day reconstruction target: deliver the verified blocker, a functioning renderer/contract fixture and a revised execution plan. A random model, unlicensed asset or synthetic mesh cannot be presented as real reconstruction success.

If ground truth is not available by Day 3, freeze a two-track report: synthetic correctness/quality experiments plus explicitly unpaired real-image diagnostics. Continue useful engineering, but downgrade accuracy and novelty claims. Dataset access and official server turnaround are external dependencies and may exceed the deadline.

If appearance, detail or eyes fail, keep the last validated scene and mark its fallback. A complete honest coarse scene is more useful than an untested concatenation of six outputs. C5 refinement is optional for the delivered pipeline; correctness of the fixed scene is mandatory for an integrated-render claim.

## Scope levels

- **Baseline:** one geometry method, captured-color or verified albedo maps, declared material defaults, conservative detail/eye fallbacks, correct Cycles scene and basic reproducibility.
- **Improved:** controlled comparison of a runnable challenger per key component, visibility-aware projection and one or two accepted bounded changes with measured preservation and costs.
- **Ultimate, beyond fourteen days:** richer intrinsic materials/UV completion, learned confidence, retrained detail/eye priors, multi-source training and short video. The [training backlog](09_LIMITATIONS_AND_NOVELTY.md) defines dependencies rather than promising all of these.

Daily closeout records today's artifact IDs/revisions, gate states, failures, elapsed resource cost, next dependency and open architectural questions. Main thread reconciles updates before the next component fork starts.
